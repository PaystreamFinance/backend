# Contributing

Paystream is published as an archived reference project and is not actively maintained. Before investing significant work, open an issue to confirm whether a contribution is likely to be reviewed.

Contributions must not include secrets, private infrastructure details, production wallet data, database exports, or third-party material without a compatible license. Run the documented type and security checks before submitting a pull request.

By contributing, you agree that your contribution is licensed under Apache-2.0.
