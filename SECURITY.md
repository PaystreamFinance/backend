# Security Policy

## Project status

This is an unmaintained, unaudited reference implementation. There are no supported releases or guaranteed response times. Do not deploy it with production wallets or funds without performing your own security review and dependency remediation.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private keys, wallet data, or information about a live deployment. Use GitHub's private vulnerability-reporting feature if it is available for this repository. Otherwise contact the repository owner privately through their verified GitHub profile.

Include affected files and versions, reproduction steps, impact, and any suggested mitigation. Remove all real secrets and personal data from reports.

## Scope warning

Security reports are welcome, but this archived project does not offer a bug bounty and may not receive a fix. Vulnerabilities in live third-party protocols should be reported directly to those protocols.
